## Estrutura da tabela

SQL usado no Supabase:

```sql
create table if not exists public.batchcutout_events (
  id bigint generated by default as identity primary key,
  event_name text not null,
  event_category text,
  event_label text,
  page_path text,
  page_location text,
  language text,
  session_id text,
  visitor_id text,
  source text,
  campaign text,
  free_limit integer,
  value numeric default 0,
  detail jsonb not null default '{}'::jsonb,
  occurred_at timestamptz not null default now(),
  created_at timestamptz not null default now()
);

create index if not exists batchcutout_events_name_idx
  on public.batchcutout_events (event_name);

create index if not exists batchcutout_events_occurred_at_idx
  on public.batchcutout_events (occurred_at desc);

create index if not exists batchcutout_events_visitor_idx
  on public.batchcutout_events (visitor_id);
```

## Consultas uteis

Endpoint interno de leitura agregada:

- `/api/stats?days=14`
- Usado pela pagina `/admin`
- Devolve totais e linhas por dia sem expor a `service_role key`
- Protegido por token temporario gerado em `/api/admin-auth`
- Requer variavel Vercel `ADMIN_PASSWORD`

Eventos por dia:

```sql
select
  date_trunc('day', occurred_at) as dia,
  event_name,
  count(*) as total
from public.batchcutout_events
group by 1, 2
order by 1 desc, 2;
```

Funil diario:

```sql
select
  date_trunc('day', occurred_at) as dia,
  count(*) filter (where event_name = 'tool_page_view') as visitas,
  count(*) filter (where event_name = 'tool_upload_started') as uploads_iniciados,
  count(*) filter (where event_name = 'batch_limit_exceeded') as tentativas_acima_3,
  count(*) filter (where event_name in ('tool_download_png', 'tool_download_zip')) as downloads,
  count(*) filter (where event_name = 'tool_pro_clicked') as cliques_pro,
  count(*) filter (where event_name = 'pro_submit_attempt') as tentativas_pro
from public.batchcutout_events
group by 1
order by 1 desc;
```
